# BootReady

**부팅이 끝났다는 걸, 이제는 알 수 있습니다.**

Windows PC를 켜면 바탕화면은 보이는데 한동안 버벅이는 구간이 있습니다. 그 순간이 언제 끝나는지 — BootReady가 정확히 포착해서 트레이 아이콘으로 조용히 알려줍니다.

---

## 주요 기능

**부팅 완료 감지**  
시작프로그램이 모두 뜨고 일정 시간 동안 새 프로세스가 없으면 완료로 판단합니다. 아무 알림 없이 트레이 아이콘만 표시됩니다.

**부팅 점수**  
100점 만점으로 이번 부팅을 평가합니다. 총 소요 시간, 느린 프로그램 수, 시작프로그램 개수를 기준으로 계산하며 감점 이유도 확인할 수 있습니다.

**시작프로그램별 소요 시간**  
어떤 프로그램이 얼마나 걸렸는지 목록으로 보여줍니다. 느림·실패 필터, Microsoft 시스템 프로그램 숨기기를 지원합니다.

**부팅 기록**  
최근 20회 부팅 이력을 보관합니다. "요즘 부팅이 느려진 것 같은데"를 데이터로 확인할 수 있습니다.

**부팅 완료 시 URL 자동 열기**  
매일 아침 제일 먼저 여는 사이트(이메일, 업무 대시보드 등)를 등록해두면 부팅이 끝나는 순간 자동으로 열립니다.

---

## 이런 분께 맞습니다

- 부팅 시간이 늘어난 것 같아서 원인을 알고 싶은 분
- 어떤 시작프로그램이 느린지 파악하고 싶은 분
- 매일 아침 루틴이 있어서 부팅과 동시에 브라우저가 열려있으면 좋겠는 분

> 시작프로그램을 직접 켜고 끄는 관리 기능은 없습니다. 그건 작업 관리자(Ctrl+Shift+Esc → 시작 프로그램)에서 할 수 있습니다.

---

## 다른 도구와 비교

| | BootReady | 작업 관리자 | Autoruns | CCleaner 등 |
|---|---|---|---|---|
| 부팅 완료 시점 알림 | ✅ | ❌ | ❌ | ❌ |
| 프로그램별 실제 소요 시간 | ✅ (ms 단위) | 영향도만 (상/중/하) | ❌ | ❌ |
| 부팅 점수 + 이력 | ✅ | ❌ | ❌ | ❌ |
| 부팅 완료 시 URL 자동 열기 | ✅ | ❌ | ❌ | ❌ |
| 시작프로그램 켜기/끄기 | ❌ | ✅ | ✅ | ✅ |
| 설치 없이 사용 | ❌ | ✅ (기본 내장) | ✅ | ❌ |

**작업 관리자**는 시작프로그램 목록과 영향도(상/중/하)를 보여주지만, 실제로 얼마나 걸렸는지는 측정하지 않고 부팅이 언제 끝났는지도 알 수 없습니다.

**Autoruns(Sysinternals)**는 자동 실행 항목을 가장 세밀하게 보여주는 도구지만, 부팅 시간 측정이나 이력 기능은 없고 일반 사용자에겐 너무 복잡합니다.

**CCleaner 류 최적화 도구**는 시작프로그램 관리에 초점을 맞추고 있어서, 관리는 할 수 있어도 "지금 부팅이 끝났다", "오늘 부팅은 몇 점이다" 같은 피드백은 주지 않습니다.

BootReady는 이 도구들을 대체하지 않습니다. 시작프로그램 정리는 작업 관리자나 Autoruns로 하고, BootReady는 그 결과를 측정·기록하는 역할입니다.

## 설치 및 사용

[Releases](../../releases) 에서 최신 `BootReady_*_x64-setup.exe`를 받아 설치하면 됩니다.

설치하면 시작프로그램에 자동 등록됩니다. 다음 부팅부터 트레이 아이콘이 표시됩니다.

- **Windows 10 / 11** 전용
- 설치 용량: 약 5 MB

---

## 구조

```
bootready/
├── bootready-ui/       # Tauri v2 + React — 단일 프로세스 (백그라운드 감시 + 트레이 + UI)
└── legacy/
    └── boot-core/      # (deprecated) 1.0.x까지 사용하던 별도 프로세스. 히스토리 보존용
```

## 개발 환경 준비

### 1. Rust 설치
```powershell
winget install Rustlang.Rustup
rustup toolchain install stable-x86_64-pc-windows-msvc
```

### 2. Node.js 설치
```powershell
winget install OpenJS.NodeJS.LTS
```

## 개발

```powershell
cd bootready-ui
npm install
npm run dev        # Tauri + Vite 개발 서버
```

### 릴리스 빌드
```powershell
npm run build      # src-tauri/target/release/bundle/nsis/BootReady_{version}_x64-setup.exe
```

## 아키텍처 (v1.1.0+)

단일 프로세스로 통합:

```
[부팅]
  BootReady.exe (Tauri v2 + Rust)
    ├── 레지스트리 + 시작폴더에서 시작프로그램 목록 수집
    ├── 500ms 간격으로 프로세스 폴링
    ├── 완료 감지 → SQLite에 세션/이벤트 기록
    ├── 부팅 완료 시 등록된 URL 자동 오픈 (uptime 가드 포함)
    ├── 앱 시작 시 GitHub에서 업데이트 확인 (1회)
    └── show.signal → 자동 팝업

[사용자 클릭]
  React UI
    ├── 타임라인 / 이력 / 점수
    └── 설정 (자동시작, URL 등록, 감지 옵션)
```

## 주요 경로

| 파일 | 경로 |
|------|------|
| DB | `%APPDATA%\BootReady\data.db` |
| 설정 | `%APPDATA%\BootReady\config.json` |
| 시그널 | `%APPDATA%\BootReady\show.signal` |
